# Hero Selector Card

This is a Hero Selector Card project where you can view hero cards featuring popular superheroes like Iron Man, Spider Man, and Captain America. Each card displays the hero's name along with the background image and a member description.

## Features
- Displays hero cards with background images and member descriptions.
- Responsive layout that adapts to different screen sizes.
- Clean and simple design, making it easy to integrate into other projects.

## Installation

To use this project locally:

1. Extract the ZIP file.

2. Open the `index.html` file in your browser.

3. Ensure you have the necessary styles by including the `style.css` file in your `css/` folder.

## Files
- `index.html`: The HTML structure for the hero selector cards.
- `css/style.css`: The CSS file for styling the project.
